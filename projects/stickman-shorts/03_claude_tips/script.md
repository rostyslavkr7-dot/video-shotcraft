# «Лёша сжёг лимит» — сценарий + промпты (Seedream / Seedance)

## Текст диктора (рус., ~48 с)
1. Лёша сжёг весь лимит Claude за час. И вот почему.
2. Он вёл всё в одном бесконечном чате. А Claude перечитывает всю переписку перед каждым ответом — чем длиннее чат, тем дороже каждое сообщение.
3. Правило первое: новая задача — новый чат.
4. Второе: не пиши «нет, не так» десятью сообщениями. Отредактируй свой запрос.
5. Третье: постоянные файлы и инструкции — в Проект. Не объясняй одно и то же заново.
6. Простые вопросы — модели полегче. Тяжёлую — только для сложного.
7. Коннекторы — это руки Claude: почта, календарь, диск. Но каждый включённый занимает место. Выключай лишние.
8. А Claude Code работает прямо с твоим проектом: читает код, запускает команды. Команды /clear и /compact чистят и сжимают память.
9. Через неделю Лёша успевал вдвое больше. С тем же лимитом.
10. Сохрани — чтобы не сжечь свой.
